# 剥头皮仓位计算器

输入入场点、止损点、最大风险U，反推建议名义仓位U，并同时显示 1R、2R 目标位。

核心公式：

```text
仓位U = 风险U * 入场价 / abs(入场价 - 止损价)
```

仓位U会向下取整，复制按钮只复制纯数字，方便直接粘贴到交易所。

目标位按方向自动计算：

```text
做多：1R = 入场价 + abs(入场价 - 止损价)
做空：1R = 入场价 - abs(入场价 - 止损价)
2R 同理扩大 2 倍
```

## 实时成本估算

公开版：<https://jiangjunfeng1027.github.io/scalp-position-calculator/cost.html>

打开 `cost.html`，选择平台与合约，输入止损距离和价格风险后，页面会自动：

- 反推理论仓位，并按交易所数量步进向下取整；
- 读取币安 U 本位或 Hyperliquid 主市场/XYZ 的公共盘口；
- 计算当前、滚动中位与最近 20 / 60 / 120 个不重复盘口的最差成本占风险，默认 60 个；
- 支持“市价进＋市价止”和“Post-only 限价进＋市价止”两种口径；
- Hyperliquid 原始 20 档不足时，自动改用官方单一聚合盘口扩展容量，并明确标记为近似值；
- 拆分双边手续费、价差、买卖冲击与扫档容量；
- 在公开快照深度不足、超过市价数量上限或费率未知时阻断结果，不做线性外推。

限价结论只在 Post-only 挂单全额成交后成立；未成交时仓位和交易成本均为 0。止损滑点只把当前盘口形状平移到计划止损价，不是未来成交预测。

默认费率是公开规则推导值，可在页面手动覆盖。工具不连接账户、不读取密钥、不会下单。

建议通过本地 HTTP 服务打开，以启用 PWA 缓存：

```bash
python3 -m http.server 8765 --directory .
```

然后访问 `http://127.0.0.1:8765/cost.html`。

计算核心测试：

```bash
node tests/cost-core.test.js
```
