## 为什么需要它？

很多仓位计算器只做这一道题：

```text
名义仓位 = 价格风险 ÷ 止损距离
```

公式没有错，但它漏掉了真实交易里最容易被低估的三笔钱：**手续费、买卖价差和大单扫盘冲击**。

例如你每单只愿意亏 200U，止损越窄，反推出的仓位就越大；仓位越大，盘口成本往往不是线性增加。最后止损虽然写着 200U，真实亏损可能是 210U、230U，甚至更多。对短线交易来说，策略优势常常不是输给方向，而是被摩擦一点点磨光。

这个工具专门解决四个痛点：

1. **固定风险不等于固定总亏损**：止损命中后，还要把执行摩擦加回来。
2. **同一标的，小仓和大仓不是同一种成本**：程序按公开可见深度逐档计算；Bybit 仅为 LP 指示性参考深度，不拿小单滑点线性外推。
3. **单张快照很会骗人**：同时保留当前、中位与最近 20 / 60 / 120 个不重复盘口的最差值。
4. **平台费率结构不同**：百分比手续费、每手固定佣金、合约乘数和数量步进分别建模。

## 30 秒怎么用？

1. 选择平台与合约。
2. 输入你的**止损距离**和愿意承担的**价格风险 U**。
3. 选择“市价进＋市价止”或支持平台的“限价进＋市价止”。
4. 等稳健窗口积累，优先看**滚动最差成本 / 风险**是否低于你的红线。
5. 记录实际名义仓位、止损命中总亏、手续费、价差、冲击和扫档深度。

默认风险只包含价格止损，不包含摩擦：

```text
理论仓位 = 风险U ÷ 止损百分比
实际总亏 = 步进取整后的价格风险 + 手续费 + 价差与盘口冲击
成本占风险 = 执行摩擦 ÷ 输入风险U
```

### Bybit 黄金与白银特别说明

- XAUUSD+ 按 **100 盎司/手**，XAGUSD 按 **5,000 盎司/手**计算；最小与步进均为 0.01 手。
- 紧点差模式金属佣金为**完整开平交易合计 6U/手**，官方说明在开仓时一次扣除，不会再按两条腿乘二。
- 保证金按公开分层规则估算，并假设没有同品种既有仓位；新闻和收开盘时可能临时降低杠杆。
- Bybit 的 CFD 深度是多家流动性提供商给出的**参考流动性**，不是撮合订单簿，也不保证完全成交。休市、报价过期或深度不够时，页面会拒绝更新并将旧值灰化。
- 当前适配使用 Bybit 官网正在使用的 TradFi WebSocket，并非承诺稳定的 V5 公共接口；协议改变时可能暂时不可用。
- 本模型对应 **Tight-Spread 紧点差账户**。请先确认账户已切换到该模式；Zero-Fee 模式的更宽点差不能套用本结果。

## 三个数字应该看哪个？

- **当前**：最后一个有效盘口，反应最快，也最容易偶然偏好或偏坏。
- **中位**：窗口里的典型成本，适合了解平常状态。
- **最差**：窗口内未经删除的真实尾部，最适合做仓位红线。默认复制它。

市价模式还提供两种口径：

- **当前买＋卖**：同一静态快照里，按实际买侧和卖侧分别扫盘。
- **较差侧×2**：把更薄的一侧复制到进出两腿，用于模拟止损时流动性变差；这是默认压力口径。

## 限价进场为什么是“条件结论”？

币安与 Hyperliquid 的限价模式只计算这个场景：**Post-only 挂单已经全额成交，随后市价止损**。进场机械滑点记为 0，但成交概率、机会成本与逆向选择不在模型内；未成交时仓位和交易成本都是 0。

止损滑点只是把当前盘口形状平移到计划止损价，**不是未来止损成交保证**。Bybit CFD 不是同一种 Post-only 撮合模型，因此首版禁用该按钮，避免把条件单误算成零滑点 Maker 成交。

## 工具刻意不做什么？

- 不连接账户、不读取密钥、不下单，也不上传你的风险参数。
- 不把公开盘口不足的部分按末档价格外推。
- 不把 Hyperliquid 原始档位与聚合档位相加，避免重复计算同一批挂单。
- 不把 Bybit 指示性深度包装成保证可成交量。
- 不包含资金费、隔夜费、触发延迟、未来跳空、清算与网络延迟。

这不是回测，也不是收益承诺；它只回答一件事：**按现在看得见的费用和流动性，你计划中的这一单有多重。**

## 手机安装与隐私

网站是纯静态网页，可在 iPhone Safari 或 Android Chrome 中“添加到主屏幕”。应用统一使用**黑金 %R**品牌标识：它代表“执行成本占本单风险（Risk）的比例”，正是这个工具最重要的判断尺度。

所有计算都在浏览器本地完成。网页只访问交易平台的公共行情端点，不保存交易所账号、API 密钥或持仓。
